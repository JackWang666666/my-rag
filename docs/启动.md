# 启动与关闭

本项目的服务分两部分：**基础设施（容器）** 和 **应用（前端 + 两个后端）**。
下面分别说明如何启动和关闭。

## 一、启动

### 1. 起基础设施（Docker 容器）

```bash
cd docker
cp .env.example .env        # 首次才需要；至少填 JWT_SECRET 和一个 LLM key
docker compose up -d        # etcd + MinIO + Milvus + Neo4j + Attu
docker compose ps           # 等到 milvus / neo4j 都是 healthy
```

- 启动前先确认 Docker Desktop 已经打开、引擎正常（`docker info` 能看到 `Server Version`）。
- `JWT_SECRET` 用 `openssl rand -hex 32` 生成；留空则两个后端各生成一个随机密钥，切后端会被踢回登录页。

### 2. 起应用（本地跑后端 + 前端）

**Python 后端**（端口 8000）：

```bash
cd langchain-rag
python -m venv venv && source venv/bin/activate   # 首次才需要
pip install -r requirements.txt                   # 首次才需要
cp .env.example .env                              # 首次才需要；与 docker/.env 保持同样的 JWT_SECRET 和 DB_PATH
uvicorn main:app --reload --port 8000
```

**Java 后端**（端口 8080，需要 JDK 17）：

```bash
cd spring-ai-rag
mvn spring-boot:run
```

**前端**（端口 3000）：

```bash
cd frontend
npm install                     # 首次才需要
cp .env.example .env.local      # 首次才需要
npm run dev
```

打开 <http://localhost:3000>。首次登录用 `ADMIN_USERNAME`（默认 `admin`）；
`ADMIN_PASSWORD` 没设的话，后端启动日志里会打印一次随机密码。

### 3. 验证

```bash
curl http://localhost:8000/health   # Python 后端 → {"status": "healthy"}
curl http://localhost:8080/health   # Java 后端 → {"status": "healthy"}
```

## 二、关闭

关闭顺序：**前端 → 两个后端 → Docker 容器 → 退出 Docker Desktop**。
最后退出 Docker Desktop 才能真正释放后台虚拟机占的内存。

### 1. 关前端和后端（本地进程）

**方式 A：在启动它们的终端里按 `Ctrl + C`**（对应 `npm run dev`、`mvn spring-boot:run`、`uvicorn ...` 三个窗口）。

**方式 B：按端口杀进程**（窗口已关也能用）：

```bash
lsof -ti :3000 | xargs kill    # 前端
lsof -ti :8080 | xargs kill    # Java 后端
lsof -ti :8000 | xargs kill    # Python 后端
```

杀不干净时把 `kill` 换成 `kill -9`。

### 2. 关 Docker 容器

```bash
cd docker
docker compose down
```

- `down` = 停止并删除容器，**数据卷保留**，下次 `up -d` 数据不丢。
- 只想暂停不删容器：用 `docker compose stop`（下次 `docker compose start` 直接起）。

### 3. 退出 Docker Desktop（释放内存的关键一步）

```bash
osascript -e 'quit app "Docker"'
```

或点菜单栏右上角小鲸鱼图标 → **Quit Docker Desktop**。
**不要手动杀进程**，否则后台引擎会变成僵尸状态，下次点 restart 会没反应。

### 4. 验证全关干净

```bash
lsof -ti :3000 :8080 :8000                      # 无输出 = 应用已关
docker ps -a                                     # 无容器 = 容器已清
pgrep -fl 'Docker Desktop|com.docker.backend'   # 无输出 = Docker 已退
```

## 三、常见问题

**Docker Desktop 点了 restart 没反应？**

多半是之前手动杀过进程，后台引擎（`com.docker.backend`）卡成僵尸状态，UI 按钮救不了。解决：

```bash
osascript -e 'quit app "Docker"'
sleep 3
pkill -9 -f 'Docker Desktop'
pkill -9 -f '/Applications/Docker.app'
open -a Docker
```

然后重新 `cd docker && docker compose up -d` 拉起容器。

**`mvn spring-boot:run` 编译报错？**

Spring 后端要求 JDK 17（8 和 11 都编不过）。先确认当前用的 JDK：

```bash
mvn -version        # 看 Java version 是不是 17
```

如果是 8，改用 brew 装好的 JDK 17（无需重新安装）：

```bash
cd spring-ai-rag
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
export PATH="$JAVA_HOME/bin:$PATH"
mvn -version        # 此时应显示 Java version: 17.0.x
mvn spring-boot:run
```

> 永久生效可把上面两行 `export` 加进 `~/.zshrc`，但会影响其他 Java 8 项目；只此项目需要 17 时建议临时 `export`。
